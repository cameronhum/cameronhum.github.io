Support

While Ago is a Windows desktop app with no account. The times stay in that copy. A JSON backup is there if you want one.

The window

While Ago runs on Windows 10 and Windows 11 as a desktop window. You log an activity on a card. The card keeps how long it has been. Workspaces keep separate sets of cards, and each one remembers its own pan and zoom. It is not currently available on the Microsoft Store, and this site has no download.

There is nothing to sign in to. Closing the window does not upload the log.

Where the times live

The app stores activities, times, notes, workspaces, card positions, and the light or dark choice in localStorage inside the WebView. On Windows that storage is on the PC, under the local app data folder for com.whileago.app. The privacy policy lists what is stored and what is not sent.

Backup

Open the header menu and choose Export backup. The app downloads a JSON file named while-ago.json into the folder you pick. Keep that file wherever you keep your own documents. Import backup reads a file you choose and writes it back onto this PC. While Ago does not send the file to a server.

If you move to another PC, copy the file yourself and import it there. Uninstalling the app removes the on-device store. A backup you already saved stays until you delete that file.

Report a bug

Use the bug report on the While Ago page. A GitHub account is required, because the form opens a GitHub issue. Say which Windows version you are on, what you did, and what you expected. Leave activity names, times, notes, and the backup file out of the message. The form sends only the text you type.

Store and payment

While Ago is not currently available on the Microsoft Store. A listing may come later. This website does not take a payment. Nothing on the donate page charges a card.
