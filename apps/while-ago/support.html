Support

While Ago is a local time tracker for Windows, on the Microsoft Store. There is no account. The times stay in that copy.

The window

While Ago runs on Windows 10 and Windows 11 as a desktop window. You log an activity on a card. The card keeps how long it has been. Workspaces keep separate sets of cards, and each one remembers its own pan and zoom. It is a Microsoft Store app. Microsoft handles the listing.

There is nothing to sign in to. Closing the window does not upload the log.

Where the times live

The app stores activities, times, notes, workspaces, card positions, and the light or dark choice in localStorage inside the WebView. On Windows that storage is on the PC, under the local app data folder for com.whileago.app. Uninstalling While Ago removes that data with the app. The privacy policy lists what is stored and what is not sent.

Report a bug

Use the bug report on the While Ago page. A GitHub account is required, because the form opens a GitHub issue. Say which Windows version you are on, what you did, and what you expected. Leave activity names, times, and notes out of the message. The form sends only the text you type.

Store and payment

While Ago is a Microsoft Store app. Microsoft handles the listing. This website does not take a payment. Nothing on the donate page charges a card.
