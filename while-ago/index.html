While Ago

Cameron S Humphries

While Ago is a Windows desktop app by Cameron S Humphries. It keeps the time of things you do, things you would rather do less, and things you only want to remember. Each one is a card on a canvas. A card grows as more time passes since you last logged it.

The Microsoft Store listing is not open yet. This page does not take a payment.

What it can do

While Ago is a local tracker. The picture is the canvas. You log something and the card remembers when. Leave it, and the card grows with the time that has passed.

  • Activities are cards. Marking one done writes the time and the card returns toward its home size.
  • The canvas pans and zooms. That view is remembered for each workspace.
  • Workspaces keep separate sets of cards. A new workspace starts empty.
  • List and Chart show the same activities another way.
  • An expected rhythm can be daily, every few days, weekly, monthly, custom, or learned from the gaps you have already logged.
  • A card can be for something you want to do more, something you want to do less, or something you only want to track.
  • Search, light and dark, and archive.
  • Export backup downloads a JSON file. Import backup brings that file back.

A local time tracker for Windows

While Ago keeps the times on the computer where you type them. The cards sit in a cluster with a soft cloud behind them. You move around the canvas. A card that has waited longer takes more space, so a quiet one is easier to see. The card shows the elapsed time, and it can say when that wait is past the usual gap.

You can switch workspace, change between canvas, list, and chart, and open a card to log an earlier time. No account is required.

Canvas

The canvas is the main view. Cards that have waited longer take more space, so the ones that have been quiet are easier to see. Drag a card to move it. The space between cards stays clear. Pan and zoom are kept for that workspace, and the first visit fits every card in view.

Workspaces

Personal and work are separate canvases. The names sit in the header. Adding a workspace starts it with no activities. Switching workspace jumps straight to that canvas, including its cloud, and restores the pan and zoom you left there.

List and chart

List shows the same activities as names and times, which is easier when you want to scan. Chart shows how the logs sit over time. Both read the activities already on this PC. Changing the view does not upload them.

Search and archive

Search filters the activities by name. Archive sets a card aside and keeps its history, so the canvas can stay on the activities you still want in front of you. Light and dark is saved on this PC and is still selected the next time you open the window.

Backup

Export backup, in the header menu, downloads a JSON file named while-ago.json. Import backup reads a file you choose and puts those activities back on this PC. The file stays where you save it. While Ago does not send it. The steps are also on the support page.

On your PC

While Ago 0.1.0 runs in a Windows desktop window on Windows 10 and Windows 11. The window is drawn with the Microsoft Edge WebView2 runtime, which Windows 11 includes and which current Windows 10 installs include as well. The times, notes, workspaces, card positions, pan and zoom, and the light or dark choice are saved on that PC so they are still there the next time you open the app. They stay on that PC.

There is no account and no sign-in. While Ago does not show ads, does not include analytics, and does not send what you log to Cameron S Humphries or to anyone else. The Microsoft Store listing is not open yet. This website does not take a payment.

FAQ

What is While Ago?

While Ago is a Windows desktop app by Cameron S Humphries. It keeps the time of things you do, things you would rather do less, and things you only want to remember. Each activity is a card on a canvas.

What can While Ago do?

You log an activity and the card shows how long it has been. Cards sit in a cluster you can pan and zoom. Workspaces keep separate sets of cards, and each workspace remembers its own view. There is also a list and a chart. You can search, switch light and dark, archive a card, and export or import a JSON backup.

Does While Ago need an account?

No. There is no sign-in. While Ago does not show ads and does not include analytics. The times stay on the PC.

Where are the times stored?

On Windows the app stores its data in localStorage inside the WebView that draws the window. That storage lives on the PC, under the local app data folder for com.whileago.app. It is not uploaded.

Can I back up While Ago?

Yes. The header menu has Export backup, which downloads a JSON file named while-ago.json. Import backup reads that file back onto the device. The file stays wherever you save it. While Ago does not send the file.

Which versions of Windows run While Ago?

While Ago 0.1.0 is a desktop app for Windows 10 and Windows 11. The window is drawn with the Microsoft Edge WebView2 runtime, which Windows 11 includes and which current Windows 10 installs include as well.
