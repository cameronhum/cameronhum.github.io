Privacy

While Ago, a local-first time tracker for Windows, by Cameron S Humphries. 8 November 2026.

While Ago is a Windows desktop app. It keeps a personal log of activities on the PC where you use it. There is no account, no sign-in, and no server for that log. Cameron S Humphries does not receive what you log.

No account

While Ago does not ask for a name, an email address, or a password. It does not create a user id. Opening the app does not sign you in to anything. The same copy of the app on one PC is the whole product. Another PC does not see the log unless you carry a backup file there yourself.

What is stored on the device

The app stores its own data on that Windows PC so the canvas is still there the next time you open the window. That data is:

  • Activity names, and whether a card is for something you want to do more, something you want to do less, or something you only want to remember.
  • The times you log, including a time you enter after the fact, and the history of those entries.
  • Notes you type on an entry.
  • The rhythm you set for a card, and a rhythm the app learns from the gaps already saved on the device.
  • Card positions and sizes, and which workspace a card belongs to.
  • Workspace names, and the pan and zoom you left on each workspace.
  • Whether a card is archived.
  • The light or dark choice.

On Windows this is kept in localStorage inside the WebView that draws the window. That storage lives on the PC, under the local app data folder for com.whileago.app. It is not a cloud account.

If you use Export backup, the app downloads a JSON file named while-ago.json. That file contains the same kind of data. It stays in the folder you save it to. Import backup reads a file you choose and writes it back into the on-device store. The app does not upload the file.

What is not sent

While Ago does not transmit the log. In ordinary use it does not send:

  • Activity names, times, notes, workspaces, card layout, or the light or dark choice.
  • The backup file.
  • An analytics event, a telemetry ping, or a crash report to Cameron S Humphries.
  • An advertising identifier. The app does not show ads.
  • A contact list, a location, a photo library, or the contents of other programs.

The publisher does not sell personal information, and does not share the log with a data broker, an ad network, or another app. There is no log on a server to share.

What leaves the PC only if you choose

A few actions are separate from the tracker, and only happen when you take them.

The bug report on the While Ago page opens a GitHub issue form. It sends the text you type, and it does not attach your activities, times, notes, or backup file. A GitHub account is GitHub’s. While Ago does not receive your GitHub password. Leave the activity log out of the message.

The Ko-fi link opens another site. A gift there is optional. While Ago does not send the activity log to Ko-fi, and a gift does not create a While Ago account. The donate page does not take a payment itself.

This website is a set of static pages. It does not ask you to sign in, and it does not run the tracker.

Microsoft Store

While Ago is intended as a Microsoft Store app. The listing is not open yet. This website does not sell the app and does not take a card payment.

If Microsoft lists the app later, Microsoft handles the store account and the listing. If a purchase is offered, Microsoft processes the payment. Cameron S Humphries does not receive your card number, billing address, or Microsoft account password. A store purchase would not upload the activity log.

How long it stays, and how to remove it

The on-device data stays until you remove it. Archiving a card keeps its history on the PC and takes it off the canvas you are looking at. Changes you make in the app are saved on the same PC.

Uninstalling While Ago removes the data the app stored for com.whileago.app with the app. A backup file you already saved somewhere else stays until you delete that file. Emptying the recycle bin, or deleting the file from the folder you chose, is what removes the backup.

Children

While Ago is not made for children. It does not ask for a name or an age, and it has no account that could record one. It cannot tell who is sitting at the PC.
