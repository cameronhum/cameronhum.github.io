Support

Local data. A JSON backup if you want one.

While Ago has no account to sign in to, and no server that keeps your times. On Windows it is a desktop window. What you log stays in that copy.

A backup is a JSON file from the header menu. Export backup saves it. Import backup brings that file back onto the device. There is no ad banner. This page does not take a payment.

Questions can go through the bug report on the While Ago page.
